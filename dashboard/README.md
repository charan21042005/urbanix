# 🗺️ Geospatial Dashboard
![Status](https://img.shields.io/badge/Status-Planned%20(Days%2010--11)-success)

## Purpose
A web-based interface providing a real-time, unified view of the Urbanix smart city state.

## Core Features
- **Geospatial Visualization:** Maps showing active sensors and current readings.
- **Predicted Risk:** Visual overlays of forecasted congestion and AQI heatmaps.
- **Route Visualization:** Displays optimal vs. congested paths based on GraphX outputs.
- **API Layer:** Serves data from Parquet/Spark outputs to the frontend.

**Current Status:** Planned for Days 10–11. No dashboard or API code implemented yet.
