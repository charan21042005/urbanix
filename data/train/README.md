This directory contains the immutable, chronological training dataset generated by the Day 4 feature engineering pipeline (`services/streaming/prepare_training_data.py`). It is the dedicated training source used by Apache Spark MLlib in Day 5 to fit both the Linear Regression baseline and the Decision Tree Regressor.

---

## 📊 1. Dataset Profile & Chronological Accounting

- **Source Lineage:** Formed from the 480 watermarked 5-minute tumbling windows in `data/feature_table/traffic/`.
- **Chronological Split Cutoff:** `2012-03-01 06:24:00 UTC` (strictly 80% elapsed time of the 8-hour 5-minute observation window).
- **Total Training Rows:** **365 rows** across all 5 municipal zones:
  - 73 window positions per zone $\times$ 5 zones = 365 rows.
- **Temporal Window Range:** `2012-03-01 00:00:00 UTC` to `2012-03-01 06:15:00 UTC`.
- **Target Label Horizon:** Future average velocity $y = \text{next\_avg\_speed\_kmph}$ strictly occurring at $t+1 \le \text{2012-03-01 06:20:00 UTC}$.
- **Boundary Guard:** 5 boundary-crossing rows (whose features fell before the cutoff but whose future target extended past the cutoff) were discarded by the Day 4 Continuity Guard to guarantee **zero temporal data leakage**.

## 🏛️ 2. Schema Definition

```
root
 |-- window_start: timestamp (nullable = true)           # Window start timestamp (UTC)
 |-- window_end: timestamp (nullable = true)             # Window end timestamp (UTC)
 |-- zone_id: string (nullable = true)                   # Municipal zone: zone_1 .. zone_5
 |-- avg_speed_kmph: double (nullable = true)            # Current window mean velocity (km/h)
 |-- min_speed_kmph: double (nullable = true)            # Current window minimum velocity (km/h)
 |-- max_speed_kmph: double (nullable = true)            # Current window maximum velocity (km/h)
 |-- speed_spread_kmph: double (nullable = true)         # Velocity spread (max - min)
 |-- traffic_record_count: long (nullable = true)        # Aggregated detector reading count
 |-- hour_of_day: integer (nullable = true)              # UTC hour (0 to 6)
 |-- day_of_week: integer (nullable = true)              # Day of week (1 to 7)
 |-- is_weekend: integer (nullable = true)               # Binary indicator (0 = weekday, 1 = weekend)
 |-- sin_hour: double (nullable = true)                  # Diurnal harmonic encoding: sin(2 * pi * hour / 24)
 |-- cos_hour: double (nullable = true)                  # Diurnal harmonic encoding: cos(2 * pi * hour / 24)
 |-- zone_index: double (nullable = true)                # Deterministic StringIndexer encoding: 0.0 to 4.0
 |-- features: vector (nullable = true)                  # 9-dimensional VectorUDT feature vector
 |-- next_avg_speed_kmph: double (nullable = true)       # Supervised target label: speed at t + 1 (km/h)
```

---

## 🎯 3. Feature Vector Specification ($\mathbf{x} \in \mathbb{R}^9$)

The `features` column is an assembled Spark `VectorUDT` containing exactly 9 dimensions:
1. `avg_speed_kmph` (Current mean speed)
2. `min_speed_kmph` (Current minimum speed)
3. `max_speed_kmph` (Current maximum speed)
4. `speed_spread_kmph` (Current speed spread)
5. `traffic_record_count` (Traffic sensor density)
6. `hour_of_day` (Linear time feature)
7. `sin_hour` (Cyclic diurnal sine component)
8. `cos_hour` (Cyclic diurnal cosine component)
9. `zone_index` (Categorical spatial zone index)
