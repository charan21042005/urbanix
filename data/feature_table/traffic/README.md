This directory contains the partitioned columnar Parquet feature table generated by the PySpark Structured Streaming query `traffic_query` (`services/streaming/streaming_job.py`). It serves as the direct source data for the Day 4 feature engineering and chronological train/test split pipeline.

---

## 📊 1. Dataset Profile & Accounting

- **Source Kafka Topic:** `traffic-topic` (sensor telemetry replayed from Caltrans PeMS METR-LA dataset).
- **Total Valid Window Records:** **480 rows** (96 five-minute temporal window positions $\times$ 5 municipal zones).
- **Temporal Coverage:** `2012-03-01 00:00:00 UTC` to `2012-03-01 08:05:00 UTC` (8 hours 5 minutes).
- **Physical Bounds:** Vehicle velocities are verified to lie within realistic physical highway limits: $0 < v \le 250\text{ km/h}$.

---

## 🏛️ 2. Schema Definition

```
root
 |-- window_start: timestamp (nullable = true)           # Start of 5-minute tumbling window (UTC)
 |-- window_end: timestamp (nullable = true)             # End of 5-minute tumbling window (UTC)
 |-- zone_id: string (nullable = true)                   # Municipal Zone: zone_1, zone_2, zone_3, zone_4, zone_5
 |-- avg_speed_kmph: double (nullable = true)            # Arithmetic mean speed across loop detectors in zone
 |-- min_speed_kmph: double (nullable = true)            # Minimum instantaneous speed recorded in window
 |-- max_speed_kmph: double (nullable = true)            # Maximum instantaneous speed recorded in window
 |-- speed_spread_kmph: double (nullable = true)         # Velocity spread within window (max - min)
 |-- traffic_record_count: long (nullable = true)        # Total individual detector readings aggregated
```

---

## 🔄 3. Downstream Transformation (Day 4 & Day 5 ML Lineage)

The 480 raw rows in this feature table undergo rigorous chronological filtering and supervised transformation in `services/streaming/prepare_training_data.py`:

```text
480 Raw Window Rows
  ├── Physical Speed Filter: 0 dropped (480 retained)
  ├── Continuity Gap Exclusion: 5 dropped at 00:10 UTC (900s gap to 00:25 UTC)
  ├── Terminal Window Exclusion: 5 dropped at 08:05 UTC (no t+1 label)
  └── Boundary-Crossing Exclusion: 5 dropped at 06:20 UTC (target falls after 06:24 cutoff)
-----------------------------------------------------------------------------------------
465 Valid Supervised Modeling Samples
  ├── data/train/ : 365 rows (80% chronological split, targets <= 06:20 UTC)
  └── data/test/  : 100 rows (held-out split, features >= 06:25 UTC)
```
