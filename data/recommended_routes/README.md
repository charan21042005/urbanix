This directory contains the operational route recommendation snapshot generated by the Scala Spark GraphX routing engine (`urbanix.graphx.RouteRecommender`). It represents the **Day 10 geospatial dashboard handoff contract**.

---

## 🏛️ 1. Architecture & Design Rationale

### Why Overwrite Mode is Correct Here
Unlike the historical feature table (`data/feature_table/traffic`) which permanently appends time-series facts, the route recommendation table uses **OVERWRITE** semantics:
- Drivers and navigation dashboards require the **single current optimal route** from the configured origin.
- Yesterday's routes are not "wrong" — they are simply stale and irrelevant for real-time dispatch.
- Overwriting ensures reading `data/recommended_routes/` is an $O(1)$ point query without requiring downstream clients to run expensive window or row-number aggregations.

### Schema Definition
```
root
 |-- origin_id: long (nullable = true)                   # Starting intersection ID (e.g. 1L Civic Center)
 |-- destination_id: long (nullable = true)              # Target intersection ID (1 to 20)
 |-- path: array (nullable = true)                       # Ordered sequence of intersection IDs
 |    |-- element: long (containsNull = true)
 |-- path_formatted: string (nullable = true)            # Human-readable route string (e.g. "1 -> 2 -> 14 -> 16")
 |-- total_travel_time_hours: double (nullable = true)   # Shortest travel time in hours
 |-- total_travel_time_minutes: double (nullable = true) # Shortest travel time in minutes (ETA)
 |-- is_reachable: boolean (nullable = true)             # True if connected via directed edges
 |-- computed_at: timestamp (nullable = true)            # Wall-clock timestamp of recomputation
 |-- prediction_zones_used: integer (nullable = true)    # Number of live prediction zones utilized
 |-- fallback_applied: boolean (nullable = true)         # True if any edge defaulted to free-flow fallback
```

## 🔍 2. Inspection & Verification

To inspect the latest route recommendation snapshot using Python / PySpark:
```powershell
.\services\streaming\venv\Scripts\python -c "
from pyspark.sql import SparkSession
spark = SparkSession.builder.master('local[1]').getOrCreate()
df = spark.read.parquet('data/recommended_routes')
df.printSchema()
df.select('origin_id', 'destination_id', 'total_travel_time_minutes', 'path_formatted', 'is_reachable').show(20, truncate=False)
"
```
